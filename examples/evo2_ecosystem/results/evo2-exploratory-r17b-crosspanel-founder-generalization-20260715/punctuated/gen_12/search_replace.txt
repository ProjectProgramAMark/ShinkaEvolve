<DESCRIPTION>
Adds an evidence-based brake for over-used conservative mutation in stable regimes, while giving standard mutation a narrow rescue credit only when ecological injury stress is present and standard has either unused capacity or learned edge. The current run over-selected conservative mutation and paid a sham penalty; this keeps the injury benefit path but reduces stable-world mutation debt using accumulated success, usage, and evidence rather than a fixed clone fallback.
