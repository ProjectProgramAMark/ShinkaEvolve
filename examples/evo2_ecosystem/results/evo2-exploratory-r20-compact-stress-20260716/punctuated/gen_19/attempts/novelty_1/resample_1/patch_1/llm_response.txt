<DESCRIPTION>
Add a narrow stress-gated rescue path that can overcome clone saturation only when the population is visibly declining and the parent is ready. The current logits keep clone near 1.0 even when clone evidence is mediocre, so unused mutation operators never gather evidence. This edit adds a clone-overstay signal, a standard-parametric rescue pulse, and small rare gates for mixed/exploratory/structural only under stronger demographic stress. Mutation remains ecology-conditioned and evidence-weighted rather than unconditional.
