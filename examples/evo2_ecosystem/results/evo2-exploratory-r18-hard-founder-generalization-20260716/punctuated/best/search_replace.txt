stress_only_standard_probe
</NAME>
<DESCRIPTION>
Add a narrow rescue-only standard mutation pulse that does not depend on prior standard evidence being present. The current scheduler learns conservative mutation, but standard mutation never gets sampled on this panel, so it cannot recover the known injury-side benefit. This edit creates a bounded stress_probe_gate from ecological stress, clone underperformance, unused standard capacity, low stability, and reproduction readiness, then routes it mostly to standard mutation while subtracting from clone. Stable worlds still suppress it through stable_world/stable_lock/fragile_lock, so it should avoid broad fixed mutation and founder-tail damage.
</DESCRIPTION>
