stress_probe_standard
</NAME>
<DESCRIPTION>
Raise only the injury/stress-conditioned path for standard parametric mutation, while leaving stable worlds strongly clone-biased. The current scheduler nearly matches clone and avoids sham cost, but it starves standard mutation of evidence, so it cannot recover the known injury benefit. This edit gives standard mutation a cautious prior and a bounded stress probe that requires injury pressure, reproduction readiness, and non-stable conditions. Clone is reduced only through that same stress opportunity, limiting stable-world mutation cost and founder-tail exposure.
</DESCRIPTION>
