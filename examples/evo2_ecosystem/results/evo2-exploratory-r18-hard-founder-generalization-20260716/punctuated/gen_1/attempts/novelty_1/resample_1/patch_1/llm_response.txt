stress_readiness_scheduler

<DESCRIPTION>
Reduce stable-world mutation cost by making clone the high-confidence default unless stress, parent vigor, and operator evidence align. Conservative mutation is converted from a broad renewal mode into a narrow clone-escape mode, while standard mutation gets the main injury-rescue path only when ecological stress is present and reproduction readiness suggests variation can be exploited.
