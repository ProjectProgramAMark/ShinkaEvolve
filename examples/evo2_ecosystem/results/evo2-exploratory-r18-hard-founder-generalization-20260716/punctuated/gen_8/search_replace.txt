<DESCRIPTION>
The current scheduler effectively collapses to clone, so it preserves stable worlds but cannot learn the injury niche. This targeted edit adds a small stress-only relief channel: it opens mutation only when population decline/death/resource stress coincide with observed clone underperformance, viable parent leverage, and low stable-world no-spend pressure. It also gives conservative mutation a modest bridge role before standard mutation has evidence, while keeping exploratory, structural, and mixed actions very suppressed. The clone logit is reduced only inside that same stress-relief window, so stable-world clone behavior should remain dominant.
</DESCRIPTION>
