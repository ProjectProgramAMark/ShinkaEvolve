injury_only_standard_probe
</NAME>
<DESCRIPTION>
Add a narrow standard-mutation probe that activates only under observable ecological stress: decline or death with intake/energy scarcity, reproductive readiness, a vigorous parent, low stable-world confidence, and no severe founder-tail collapse. The current scheduler preserves sham performance but almost never samples standard mutation, leaving shock recovery negative. This edit increases standard logits only through this stress-gated path while subtracting clone pressure in the same ecological window, so stable sham worlds remain clone/conservative dominated.
</DESCRIPTION>
