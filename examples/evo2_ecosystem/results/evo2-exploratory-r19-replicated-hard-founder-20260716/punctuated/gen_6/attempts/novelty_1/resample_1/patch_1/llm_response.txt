stress_limited_standard_probe
</NAME>
<DESCRIPTION>
Add a small injury/stress-only standard-parametric trial path that is suppressed in quiet worlds and tied to observed clone weakness plus conservative evidence. The current scheduler gets a useful sham gain from conservative mutation but realizes no standard mutations, so it cannot learn whether broader parametric repair helps after persistent injury. This edit slightly raises standard only when repair_need is high, clone performance is weak, the parent can reproduce, and the world is not stable; it also trims clone probability in that same condition while leaving stable-world conservative behavior mostly intact.
</DESCRIPTION>
